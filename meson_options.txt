# Tirith "graphics": LibOS code that forwards selected syscalls (/dev and /sys access, GPU
# ioctls, mmap of host-device memory, ...) to a host agent through a shared communication page. It
# only works with a host agent present (VM/TDX PAL + QEMU sg-listener); it is inert, but still
# compiled in, under the plain Linux PAL. Disable to build the LibOS without any of it.

    description: 'Compile the Tirith graphics host-redirection paths into the LibOS')
